# Yama P3 Prayer Reminder

A manual RuneLite Java plugin with sidebar controls and a movable in-game reminder.

| Sidebar button | Overlay |
| --- | --- |
| Range | PRAY MAGE |
| Mage | PRAY RANGE |
| Clear Reminder | Hidden |

The reminder remains until you change it, clear it, or disable the plugin. It is only drawn while logged in. This plugin does not detect Yama phases or change prayers for you; it displays the opposite of the button you choose.

## Using the plugin

1. Enable **Yama P3 Prayer Reminder** in RuneLite's plugin list.
2. Click the blue **Y** icon in the right sidebar.
3. At the end of P2, click **Range** or **Mage** to record the prayer you want to select.
4. The in-game overlay displays the opposite prayer. Use **Clear Reminder** to dismiss it.

The sidebar uses large prayer-icon buttons with text labels and a highlighted selection.

## Moving the reminder

While the reminder is visible, hold **Alt** and drag it to your preferred location. If necessary, check RuneLite's overlay movement hotkey setting.
